The back of the package, without the scavenger hunt.

I kept searching for the nutrition label on foods I already had at home. I made Pantry Index because I wanted one place to look, and then decided to make it useful for anyone else with the same problem.

Why it exists

I built this because I kept looking up the same foods.

I would search for “Great Value white rice nutrition,” then do it again for oats, lentils, beans, vegetables, and milk. The information was usually somewhere, but finding the serving size and the full nutrient list took more effort than it should.

So I started putting the foods I actually use into one searchable place. It is still a work in progress and it will have gaps. My hope is simple: make the everyday lookup easier for me, then make it useful for anyone who wants to use it.

Food state

Raw, cooked, dry, canned, and frozen records keep their source descriptions. Always choose the preparation you weigh.

Sources

The expanded catalog comes from USDA SR Legacy (April 2018), a historical reference, plus source-reconciled FoodData Central records. It does not guarantee the composition of a current packaged product.

Gaps

Not every nutrient is measured for every food. A dash means unknown; a daily subtotal with incomplete data is marked ≥ and shows how many foods report it. Daily Values are general references, not personalized requirements.
