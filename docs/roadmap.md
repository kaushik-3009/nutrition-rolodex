# Roadmap

The first release is intentionally public and read-only: search, browse, select, and inspect a label.

## Next

- Verify and add Walmart / Great Value product records from package labels or a stable product source.
- Add a record review queue for source description, serving measure, state, and label verification date.
- Improve search with aliases, typo tolerance, and state-aware results.
- Add a compact mobile detail drawer so a selected label stays close to a long result list.

## Later

- Barcode lookup.
- Personal saved foods and custom serving presets.
- User-submitted records with moderation and evidence requirements.
- Comparison views for two raw ingredients or package records.

The product should not add health claims, meal tracking, or recipe calculations until the underlying food-state and serving model can support them without creating false precision.
